# 🔢 Number Statistics

## Task 5 - Level 1 - Day 5

An interactive Python project that analyzes a list of numbers and identifies even numbers, odd numbers, the largest number, and the smallest number.

The project also includes a Streamlit web application where users can enter their own numbers and instantly get the results.

---

## 📌 Project Overview

The Number Statistics project demonstrates basic numerical data processing using Python.

The program processes a collection of numbers and:

- Identifies even numbers
- Identifies odd numbers
- Finds the largest number
- Finds the smallest number
- Counts the total number of values
- Displays the results clearly

The Streamlit application makes the project interactive by allowing users to enter their own numbers.

---

## 🎯 Objectives

- Practice Python loops and conditional statements
- Understand the modulo operator `%`
- Separate even and odd numbers
- Find the largest and smallest values
- Practice basic numerical data processing
- Build an interactive application using Streamlit
